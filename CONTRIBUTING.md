# Contributing

Changes should remain read-only and generic: no vendor-specific workspace paths, credentials, remote fetches, repository writes, or import specifiers beyond Hermes' Desktop SDK/React allowlist. Add a failing regression test for behavior changes, then implement and run the commands in README. Use an isolated `HERMES_HOME` for tests and never inspect or log credentials. Keep Git subprocesses bounded by time and output, resolve user refs to SHAs, and place `--` before pathspecs. Report the exact repro and expected behavior with changes. Update the README's **Privacy and disclosure** section whenever a change adds a command, network call, file read/write or background activity.
